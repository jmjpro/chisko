# Anonymous-First Recommendation Flow

Users can complete the full upload + questionnaire + recommendation flow without creating an account. Contact information is only collected when the user chooses to act on a recommendation — the moment of highest motivation after seeing their projected savings. An anonymous session links the Home Profile, Bill Imports, and Recommendation until the user converts to a Lead. Requiring an account upfront would kill top-of-funnel conversion before users have experienced the product's core value.
