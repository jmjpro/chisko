# Affiliate Reference lives on Plan Version, not Supplier

`suppliers.trackingUrlTemplate` was added speculatively for click-through handoff but was never populated — CHI-64's source data shows each Elektra plan link carries its own `refcode`/`refid` pair, meaning the affiliate reference is specific to a Plan Version, not shared across a supplier's whole catalog. We're storing the Affiliate Reference (and the resulting outbound URL) on `planVersions` instead, and dropping `trackingUrlTemplate` from `suppliers`. This keeps it consistent with every other supplier-specific override (discount, eligibility), which already lives on `planVersions` for the same reason: plans get revised, and a revision can plausibly need a new reference even when the discount terms don't change.
