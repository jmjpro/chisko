# Per-PR ephemeral backends instead of a shared dev domain

CHI-33 originally called for a persistent `dev.chisko.app` Vercel/Convex pair shared by all non-prod work. We dropped that in favor of the Convex Vercel Marketplace integration, which gives every PR branch its own ephemeral Vercel preview deployment paired automatically with its own ephemeral Convex deployment (created on push, torn down when the PR closes/merges). There is no `dev.chisko.app` or `preview.chisko.app` domain — non-prod access happens through Vercel's auto-generated per-deployment/per-branch URLs. We chose this because a shared dev environment means concurrent PRs trample each other's data, while per-PR backends give full isolation with no extra CI scripting (the integration wires `CONVEX_DEPLOY_KEY` to Vercel, and `npx convex deploy` injects `VITE_CONVEX_URL` per deployment automatically). Production remains the only stable custom domain (`chisko.app` / `www.chisko.app`), pointed at the production Convex deployment.

Note: installing via the Vercel Marketplace always provisions a brand-new Convex team/project rather than linking an existing one. Since the app wasn't live yet, we adopted that new project (`convex-charcoal-cable`, prod deployment `watchful-hawk-468`) as production and retired the original `chisko` project (team "jmjpro's team", prod deployment `watchful-skunk-387`) rather than doing a manual deploy-key reconnection.
